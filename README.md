# 🔍 Discovery Service (Eureka Server)

Este servicio registra y permite descubrir los microservicios activos en el sistema. Facilita la comunicación entre servicios.

## Tecnologías utilizadas
- Java 17
- Spring Boot
- Spring Cloud Netflix Eureka Server
- Maven

## Funcionalidades
- Registro y descubrimiento dinámico de microservicios.
- Integración con Spring Cloud Gateway y Config Server.
